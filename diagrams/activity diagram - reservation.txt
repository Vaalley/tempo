@startuml

title Diagramme d'activite - Reservation d'un espace (Tempo)

|Collaborateur|
start
:Consulter les espaces disponibles;
:Selectionner un espace et un creneau;
:Choisir le type de reservation\n(publique ou privee);
:Confirmer la reservation;

|Systeme|
:Verifier l'authentification (JWT);
if (Authentifie ?) then (non)
    :Retourner 401 Unauthorized;
    |Collaborateur|
    :Afficher "Authentification requise";
    stop
else (oui)
endif

|Systeme|
:Verifier que l'espace existe;
if (Espace trouve ?) then (non)
    :Retourner 404 Not Found;
    |Collaborateur|
    :Afficher "Espace introuvable";
    stop
else (oui)
endif

|Systeme|
:Verifier les chevauchements\nde reservations;
if (Creneau disponible ?) then (non)
    :Retourner 409 Conflict;
    |Collaborateur|
    :Afficher "Creneau deja reserve";
    stop
else (oui)
endif

|Systeme|
:Enregistrer la reservation (CONFIRMED);

|Collaborateur|
:Afficher la confirmation de reservation;
stop

@enduml
