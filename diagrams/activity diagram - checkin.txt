@startuml

title Diagramme d'activite - Check-in / Suivi de presence (Tempo)

|Collaborateur|
start
:Ouvrir l'application Tempo;
:Acceder a "Mes reservations";
:Selectionner la reservation en cours;
:Scanner le QR code present dans la salle;

|Systeme|
:Decoder le QR code (identifiant de l'espace);
:Verifier l'authentification (JWT);
if (Authentifie ?) then (non)
    :Retourner 401 Unauthorized;
    |Collaborateur|
    :Afficher "Authentification requise";
    stop
else (oui)
endif

|Systeme|
:Verifier que la reservation existe\net que l'utilisateur est autorise\n(createur ou participant accepte);
if (Reservation trouvee et acces autorise ?) then (non)
    :Retourner 404 Not Found ou 403 Forbidden;
    |Collaborateur|
    :Afficher "Reservation introuvable\nou acces refuse";
    stop
else (oui)
endif

|Systeme|
:Verifier que le QR code correspond\na l'espace reserve;
if (QR code valide ?) then (non)
    :Retourner 404 Not Found;
    |Collaborateur|
    :Afficher "QR code incorrect\n(Mauvaise salle)";
    stop
else (oui)
endif

|Systeme|
:Verifier le creneau horaire\n(start_at <= now <= end_at);
if (Dans la fenetre de check-in ?) then (non)
    :Retourner 400 Bad Request;
    |Collaborateur|
    :Afficher "Check-in non disponible\n(hors creneau)";
    stop
else (oui)
endif

|Systeme|
:Mettre a jour le statut de la reservation;
note right
  CONFIRMED -> CHECKED_IN
end note
:Enregistrer l'heure de check-in;
:Enregistrer l'action dans le journal\nd'audit (MongoDB);

|Collaborateur|
:Afficher "Presence confirmee";
stop

@enduml
