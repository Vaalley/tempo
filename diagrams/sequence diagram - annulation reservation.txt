@startuml
title Séquence - Annulation d'une réservation (Tempo V1)
actor "Collaborateur ou\nadministrateur" as User
participant "Frontend" as Frontend
participant "API\n(routes et services)" as API
database "PostgreSQL" as DB
database "MongoDB\n(audit_logs)" as Mongo

note over Frontend, API
  JWT dans un cookie HttpOnly.
  Les écritures exigent Origin autorisé et X-CSRF-Protection: 1.
  Refus CSRF : 403 ; session invalide : 401 ; entrées Zod invalides : 400.
end note

== Consultation des réservations ==
User -> Frontend : Ouvrir les réservations
activate Frontend
Frontend -> API : GET /api/bookings
activate API
API -> API : Vérifier la session
break Session invalide
  API --> Frontend : 401 Authentification requise
  Frontend --> User : Afficher l'erreur
end
API -> DB : ADMIN : toutes les réservations\nUSER : publiques, propres ou invitation non refusée\navec espace, propriétaire et participants
activate DB
DB --> API : Réservations triées par start_at décroissant
deactivate DB
API --> Frontend : 200 - Réservations
deactivate API
Frontend --> User : Afficher la liste
deactivate Frontend

== Suppression de la réservation ==
User -> Frontend : Confirmer l'annulation
activate Frontend
Frontend -> API : DELETE /api/bookings/:id
activate API
API -> API : Contrôler CSRF, session, entrées Zod
break Requête refusée
  API --> Frontend : 401 session / 403 CSRF / 400 données
  Frontend --> User : Afficher l'erreur
end

API -> DB : Rechercher bookings par id
activate DB
DB --> API : Réservation ou absence
deactivate DB
break Réservation introuvable
  API --> Frontend : 404 Booking not found
  Frontend --> User : Afficher l'erreur
end
API -> API : Autoriser le propriétaire ou un ADMIN
break Collaborateur non propriétaire
  API --> Frontend : 403 Unauthorized
  Frontend --> User : Afficher le refus
end
API -> DB : DELETE FROM bookings WHERE id = :id RETURNING *
activate DB
note right of DB
  Les participants et le jeton QR liés
  sont supprimés en cascade.
end note
DB --> API : Réservation supprimée
deactivate DB
API -> Mongo : Tenter l'audit DELETE_BOOKING\n{ entityType, entityId, entityData, performedBy, timestamp }
activate Mongo
alt MongoDB disponible
  Mongo --> API : Audit enregistré
else Échec de connexion ou d'écriture
  Mongo --> API : Erreur
  API -> API : Journaliser l'erreur sans annuler la suppression
end
deactivate Mongo

API --> Frontend : 200 - { message: "Booking deleted", booking }
deactivate API
Frontend --> User : Retirer la réservation de la liste
deactivate Frontend
@enduml
