@startuml
title Séquence - Gestion des espaces (Tempo V1)
actor "Administrateur" as User
participant "Frontend" as Frontend
participant "API\n(routes et services)" as API
database "PostgreSQL" as DB
database "MongoDB\n(audit_logs)" as Mongo

note over Frontend, API
  JWT dans un cookie HttpOnly.
  Les écritures exigent Origin autorisé et X-CSRF-Protection: 1.
  Refus CSRF : 403 ; session invalide : 401 ; entrées Zod invalides : 400.
end note

== Création d'un espace ==
User -> Frontend : Renseigner nom, type et capacité
activate Frontend
Frontend -> API : POST /api/workspaces\n{ name, type, capacity }
activate API
API -> API : Contrôler CSRF, session, rôle ADMIN, entrées Zod
break Requête refusée
  API --> Frontend : 401 session / 403 CSRF ou rôle / 400 données
  Frontend --> User : Afficher l'erreur
end

API -> DB : INSERT INTO workspaces\n{ name, type, capacity } RETURNING *
activate DB
DB --> API : Espace créé
deactivate DB
API --> Frontend : 201 - Espace
deactivate API
Frontend --> User : Actualiser le tableau des espaces
deactivate Frontend

== Suppression d'un espace ==
User -> Frontend : Confirmer la suppression d'un espace
activate Frontend
Frontend -> API : DELETE /api/workspaces/:id
activate API
API -> API : Contrôler CSRF, session, rôle ADMIN, entrées Zod
break Requête refusée
  API --> Frontend : 401 session / 403 CSRF ou rôle / 400 données
  Frontend --> User : Afficher l'erreur
end

API -> DB : DELETE FROM workspaces WHERE id = :id RETURNING *
activate DB
note right of DB
  Cascade : réservations de l'espace,
  puis participants et jetons QR associés.
end note
DB --> API : Espace supprimé ou absence
deactivate DB
break Espace introuvable
  API --> Frontend : 404 Workspace not found
  Frontend --> User : Afficher l'erreur
end
API -> Mongo : Tenter l'audit DELETE_WORKSPACE\n{ entityType, entityId, entityData, performedBy, timestamp }
activate Mongo
alt MongoDB disponible
  Mongo --> API : Audit enregistré
else Échec de connexion ou d'écriture
  Mongo --> API : Erreur
  API -> API : Journaliser l'erreur sans annuler la suppression
end
deactivate Mongo

API --> Frontend : 200 - { message: "Workspace deleted", workspace }
deactivate API
Frontend --> User : Actualiser le tableau des espaces
deactivate Frontend
note over API, DB
  PATCH /api/workspaces/:id : parcours séparé.
  Transaction avec verrou sur l'espace ; une capacité insuffisante
  pour les participants ACCEPTED ou PENDING est refusée (409).
end note
@enduml
